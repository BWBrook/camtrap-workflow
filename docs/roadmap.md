# Roadmap

## Current Product

Goal 011 defines the lean current product and the only supported run contract.
Implementation and acceptance evidence live in
`docs/goals/011-kill-your-darlings/`.

## Acceptance Work

- complete compact local verification;
- obtain one scientific and one architecture review;
- make at most one focused repair pass;
- prove ordinary CI on the exact feature SHA;
- run one timed manual Judbury release and independent reconstruction; and
- fast-forward the accepted change only when publication is non-destructive.

## Deferred Product Decisions

Future modules require a named user question, defensible assumptions,
eligibility rules, bounded interpretation, and evidence proportional to their
maintenance cost. Possible future work is evaluated from the lean foundation;
it is not dormant functionality in the current tree.

High-value candidates after Goal 011 are an ergonomic local user interface,
additional reviewed input authorities, and expert ecological modules driven by
specific decisions. None is authorized by this roadmap.

Historical milestones remain in `docs/goals/`, `docs/log/`, `docs/audits/`,
and `docs/design/`; they do not describe the current product contract.
