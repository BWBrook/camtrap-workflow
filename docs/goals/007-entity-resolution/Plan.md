This dependency-ordered plan is planning-only. It begins only after Barry
approves the exact 13-row crosswalk and complete packet, and after the packet
is published through the exact gate in `Goal.md`.

   - Prove the packet commit subject, exact authoring parent, seven-path parent
     diff, synchronized clean `main`, and unchanged approved crosswalk.
   - Capture the pre-edit default Judbury validation-only and full evidence
     baseline, immutable bundle, latest-pointer bytes, Phase 2 records,
     validated analytical inputs, 13 scientific comparator tables, methods,
     event membership, row accounting, and target metadata.
   - Stop without editing if authority, source state, or baseline evidence is
     incomplete.

2. **Failing contract fixtures**
   - Add a Goal 007 fixture with the approved 13-to-nine Judbury mapping and
     four undirected move-pair relations.
   - Add generic four-table controls with suffix-like opaque identifiers and
     close or identical coordinates that must remain distinct.
   - Add an opaque-ID CamtrapDP fixture with explicit locations, deployments,
     and endpoints but no nominal station.
   - Add orphan, duplicate, conflict, ambiguous, reversed-interval, missing
     optional evidence, tamper, and active-run non-inference controls.
   - Write focused tests first and confirm that they fail for the absent Goal
     007 contract rather than for malformed fixture setup.

3. **Versioned entity core**
   - Add only `R/entity_resolution.R` for closed entity, link, deployment,
     summary, and join-readiness schemas.
   - Implement deterministic IDs from typed logical evidence, excluding run
     IDs, timestamps, absolute paths, coordinates, proximity, and suffix
     parsing.
   - Enforce exactly the resolution states and link types in `Goal.md`.
   - Keep `analysis_site` unselected with zero membership records.

4. **Configuration and immutable sidecar evidence**
   - Add the small provisional internal selection to `R/config.R` and only the

     before and after snapshotting, then inventory and parse only the immutable
     copy.

     unselected extra evidence.

5. **Four-table and CamtrapDP resolution**
   - For a generic four-table input, resolve legacy `site` only to
     `physical_location`; record nominal station and deployment as unresolved.
   - For the approved Judbury profile, use the exact sidecar rows without

   - For CamtrapDP, resolve only explicit `locationID`, `deploymentID`, and

   - Keep crosswalk resolution independent from deployment readiness.

6. **Supported preflight and full-path integration**
   - Invoke the resolver from the existing validation preflight after source
     snapshot/parser evidence is available and before the scientific graph.
   - Emit the five Goal 007 review artefacts in validation-only and full modes

   - Keep `validated_inputs.rds` at exactly `site`, `op`, `obs`, and `taxa`.

## Stopping boundary

analytical grouping, deployment inference, module planning, interface work, or
new ecological methods. Stop on any condition listed in `Goal.md` or
`Runbook.md`, preserve the last trustworthy evidence, and return the decision
that requires Barry rather than filling the gap by inference.
