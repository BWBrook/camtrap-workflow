# WP-0.6.1 — WildObsR evaluation

Date: 2026-01-07

## What changed
- Evaluated WildObsR integration feasibility versus `camtrapdp` for Camtrap DP ingestion.

## Evidence and outcome
- WildObsR is not currently available on CRAN (GitHub-only), increasing install friction for the core workflow.
- `camtrapdp` provides DP parsing/validation utilities needed for ingestion with lighter dependency weight.

## Decisions
- Defer WildObsR integration; adopt `camtrapdp` for ingestion (see `docs/decisions.md`).
