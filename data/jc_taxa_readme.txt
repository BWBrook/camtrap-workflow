# jc_taxa.csv: columns and descriptions:
class: Biological class (e.g., birds—'Aves').
order: Taxonomic order (e.g., 'Passeriformes').
family: Taxonomic family (e.g., 'Corvidae').
genus: Taxonomic genus (e.g., 'Corvus').
species: Specific species epithet (e.g., 'tasmanicus').
common: Common English name (e.g., 'Forest_Raven').
short: Short abbreviation or identifier for the species (e.g., 'rav').
diet: Primary dietary classification (e.g., omnivore, insectivore).
sec_diet: Secondary dietary classification, if applicable (e.g., carnivore, 'na' if not applicable).
activity: Activity pattern (e.g., diurnal, nocturnal).
habitat: Typical habitat usage (e.g., arboreal, terrestrial).
status: Ecological/native status (e.g., native).
body_size: Relative size classification (e.g., medium).
sociality: Social behavior classification (e.g., social, solitary).
mobility: Movement pattern (e.g., mobile, sedentary).
reproductive: Reproductive behavior (e.g., monogamous).
litter: Typical litter size or reproductive output category (e.g., small, multiple).
