# Changelog

All notable changes to this project are documented here.

Entries below the current unreleased section are historical release provenance
and do not describe the Goal 011 product contract.

## [Unreleased]

### Changed
- Replaced the accumulated target graph with seven explicit workflow stages.
- Added one strict current configuration and run-bundle contract.
- Made module eligibility and claim limits explicit in machine-readable status.
- Reduced delivery to one concise HTML ecological report plus audit evidence.

### Added
- Independent emitted-bundle reconstruction, including the accepted Judbury
  Jaccard oracle and protected physical-source checks.
- Current-format zero-event and CamtrapDP deployment/physical-location lineage
  coverage.

### Removed
- Product modules, orchestration, delivery paths, and dependencies outside the
  retained Goal 011 ecological core.

## [0.7.0] - 2026-01-07

### Added
- Camtrap DP ingestion and export adapters with mapping documentation.
- Teaching module with guided exercises.
- Reproducibility benchmark protocol and runtime notes.
- Methods manuscript skeleton (Quarto) tied to pipeline artefacts.
- Container recipe for reproducible runs.

### Changed
- Occupancy covariates now drop missing/zero‑variance inputs automatically.
- Functional diversity ignores single‑level trait columns (placeholder when none remain).

### Fixed
- Occupancy prediction plotting now uses correct site identifiers.
